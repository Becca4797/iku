# Ding
Ding is a travel planning app that prioritises women's safety.

## Features
Ding streamlines the safety-checking process of travelling through features like a safety score and integrating safe places into route planning. The app is very personalisable in order to tailor safety to each user. Ding also has the capability to alert emergency services as well as reroute according to live data collected via its reporting system. This particular feature was inspired by Waze and reworked to put our users' safety first. 

## Usage
Ding is designed to be intuitive to remove any barriers to staying safe. Once logged in, the search bar can be used to enter a destination then Ding will suggest multiple routes. These routes will be ranked by safety which will be indicated by a colour code - green for safest and red for most dangerous. While en route, users who may encounter dangerous situations, like active crime scenes, escalating conflicts or dangerous individuals, will have the option to flag these. This feeds Ding live data that it can use to stay up to date and route other users safely. If the user finds themselves in immediate danger, Ding provides swift access to emergency numbers, like 999 and 111.
